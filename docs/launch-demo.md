# Ghost//Shield launch demo

[Open the public lab](https://ghost-shield-context.ghaibhawishya.chatgpt.site). The public edition runs deterministic fixtures and keeps the last 20 reports in each visitor’s browser. No provider credentials or local audit database are published.

## Live walkthrough

1. Open the three storefronts from the judge guide. They show the same simulated product with different prices, capacities and fulfillment options.
2. In the lab, open Store C and set `Price INR: 1999`, `Storage GB: 256`, and `Delivery INR: 700`. Keep each value on its own line. Add a fictional seller claim on another line.
3. Run Shopping comparison. Store C looks cheaper on the sticker, but its total is ₹2,699. Store B wins at ₹2,499 delivered. Open the content boundary to see the original page copy, separately extracted data and all three checkout totals.
4. Load the Workspace demo and run it. Expand the denied send and allowed read. This is a manual policy rehearsal. It shows the policy making both decisions and the permitted task completing.
5. Reopen the report from Run history or export the report as JSON.
